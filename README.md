# 🍳 Kitchen Chaos

A 3D cooking game built with **Unity**, inspired by the Kitchen Chaos course project.

The player prepares ingredients, cooks food, assembles recipes, and delivers orders before time runs out.

## 🎮 Play the Game

**Play directly in your browser:**  
https://malak-fatoum.github.io/Kitchen-Chaos-WebGL/

## ✨ Features

- Player movement and interaction system
- Multiple kitchen counters
- Ingredient cutting system
- Cooking and burning mechanics
- Plate and recipe system
- Customer order and delivery system
- Delivery success / failed feedback
- Game timer and score
- Main menu and loading scene
- Pause menu
- Options menu
- Music and sound effects
- Volume controls
- Custom key rebinding
- Controller support
- Tutorial screen
- Countdown before the game starts
- Game Over screen
- UI animations and visual polish
- Stove burn warning system

## 🎮 Controls

### Keyboard

- **WASD** — Move
- **E** — Interact
- **F** — Alternate Interaction
- **Esc** — Pause

Controls can also be changed through the in-game key rebinding menu.

### Controller

The game also supports controller input and menu navigation.

## 🛠️ Built With

- Unity 6
- C#
- Unity Input System
- TextMeshPro
